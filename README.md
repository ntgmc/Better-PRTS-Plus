## 📦 快速安装

1. 安装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/)（油猴）。
2. 从 [GreasyFork（推荐）](https://greasyfork.org/zh-CN/scripts/558329-better-prts-plus)、[Release 镜像](https://gh-proxy.com/https://github.com/ntgmc/Better-PRTS-Plus/releases/latest/download/Better-PRTS-Plus.user.js)或 [备用镜像](https://ghfast.top/https://github.com/ntgmc/Better-PRTS-Plus/releases/latest/download/Better-PRTS-Plus.user.js)安装脚本。
3. 打开 [prts.plus](https://prts.plus)，导入干员后即可使用筛选。

## ✨ 功能一览

| 功能 | 用途 |
| --- | --- |
| 阵容与练度筛选 | 查找阵容齐全或可借助战补齐的作业，核对练度，将不符合条件的作业置灰或隐藏。 |
| 多账号管理 | 从森空岛、文件或文本导入干员，为各账号分别保存名单和练度，支持配置备份。 |
| 作业卡片增强 | 标记关注用户的作业与作业集，显示干员头像、关卡代号和上传时间，折叠长描述，整理视频链接。 |
| 页面增强 | 滚动加载更多、活动关卡快捷筛选、干员组弹窗头像，以及可选的筛选栏布局优化。 |
| 用户黑名单 | 拉黑用户并隐藏其作业和作业集，在悬浮窗中查看名单、进入主页或解除拉黑。 |

增强功能可在悬浮球中按需开关。干员和模组数据会自动更新。

## 📖 使用指南

### 导入干员

1. 点击筛选栏或悬浮球 → 账号与数据中的“森空岛导入”。
2. 在打开的森空岛网页中登录，在脚本面板选择目标账号，点击“读取并导入干员”；有多个角色时选择要导入的角色。
3. 核对预览中的账号、人数变化和练度信息，确认后返回作业站。

也可在悬浮球 → 账号与数据中点击“导入干员数据”，上传 `.json` / `.txt` 文件或粘贴文本。MAA 导出的 JSON 支持导入持有干员及练度；TXT 每行填写一个干员名称。

导入会替换目标账号的名单和练度。覆盖前请核对预览，尤其留意移除干员或清空练度的提示；仅有名称的文本会将练度标为未知。

### 筛选作业

导入后，在搜索框下方的筛选栏选择：

| 按钮 | 作用 |
| --- | --- |
| 完美阵容 | 筛选已拥有全部所需干员的作业。 |
| 允许助战 | 允许最多缺少 1 名干员，通过好友助战补齐。 |
| 校验练度 | 核对精英化、等级、技能与专精、模组和潜能，可单独开启或配合阵容筛选。 |
| 置灰模式 / 隐藏模式 | 选择不符合条件的作业如何显示。 |

卡片会显示缺少的干员、助战人选和练度提示，列表上方显示筛选统计。隐藏模式下可切换回置灰模式查看原因，练度未知的作业会保留并提示待核验。

### 账号与显示设置

点击页面侧边的悬浮球，选择分类：

| 分类 | 常用设置 |
| --- | --- |
| 作业卡片 | 关注用户作业及作业集标记、描述折叠、干员头像、关卡代号、点击关卡筛选、上传时间、视频与标签显示、练度提示样式。 |
| 页面增强 | 滚动自动加载更多、活动关卡快捷浮窗、全站样式优化、干员组弹窗头像、侧边栏和原站干员匹配设置。 |
| 黑名单 | 启用用户黑名单、查看已拉黑用户的主页、解除拉黑。 |
| 账号与数据 | 添加、切换、删除或重命名账号，导入干员，设置森空岛快捷刷新，备份与恢复配置。 |
| 关于 | 当前版本、项目资料、更新提醒和手动检查更新。 |

设置会自动保存；需要刷新才能生效时，面板会提示。添加多个账号后，也可通过筛选栏切换当前账号。

- “滚动自动加载更多”默认开启，关闭和重新开启立即生效。加载失败时，可点击原站按钮重试。
- “活动关卡快捷浮窗”在活动期间提供关卡筛选；多个活动可通过下拉框切换，手机上默认收起。
- “全站样式优化”默认关闭，开启后优化筛选栏布局与窄屏换行，并将网格卡片标题限制为两行。
- “折叠侧边栏”默认关闭。开启后作业列表占满内容区，个人主页的用户名、关注控件及关注、粉丝、作业统计保留在顶部紧凑区域；窄屏自动换行，关闭立即恢复原布局。
- “点击关卡筛选”默认关闭，开启后可点击卡片关卡标签应用筛选。
- “标记关注用户作业及作业集”默认开启。登录作业站后，未启用“只看关注”时，关注用户的作业和作业集显示蓝色侧边和“已关注”标签；打开作业集后，集内作业也按各自作者显示标记。在该用户的个人主页中省略其作品的标记，关闭设置后立即恢复原样。

### 拉黑用户

在悬浮球 → 黑名单中开启“启用用户黑名单”（默认关闭），即可在用户个人主页的信息卡中点击“拉黑此用户”。拉黑后立即隐藏该用户的作业和作业集，集内作业按各自作者判断；切换置灰模式也会保持隐藏。

在悬浮球 → 黑名单中可查看名单、点击“解除拉黑”恢复显示。只有点击名单中的用户名进入对应主页时，才会显示该用户的作业；普通主页入口和作业详情直链仍会隐藏。名单保存在本地，并随全部配置备份；关闭功能立即恢复显示，保留名单供再次开启使用。

### 森空岛快捷刷新

该功能默认关闭。在悬浮球 → 账号与数据 → 森空岛快捷刷新中开启“保存登录凭据”，阅读并同意风险告示，再为各账号导入一次，即可使用“刷新全部已保存账号”。森空岛导入面板也可设置。

| 保存方式 | 使用与风险 |
| --- | --- |
| 口令加密（默认） | 设置至少 12 个字符的独立口令，每次打开或刷新页面后解锁。口令遗忘后需清除凭据并重新导入。 |
| 免口令保存（高风险） | 凭据明文保存在油猴存储中，打开页面即可刷新。读取脚本存储、油猴备份或同步数据的人可能直接使用凭据，需单独同意此风险。 |

自动刷新默认随功能开启，每个账号距上次成功刷新满 24 小时，且作业站页面可见时运行；加密模式还需先解锁。可单独关闭自动刷新。凭据失效时，重新登录森空岛并导入即可。

登录凭据关系到账号安全，请使用与森空岛密码不同的口令，并保管好油猴存储及备份。加密模式仍依赖设备安全和口令强度；接口或平台规则变化也可能导致刷新失效或账号访问受限。关闭保存功能会清除脚本保存的凭据，保留已导入数据。

### 脚本更新

发现新版本时，弹窗展示更新内容和普通、重要或紧急级别，可立即更新、跳过当前版本，或设置仅提醒重要及紧急更新。在悬浮球 → 关于中可手动检查更新。

## 💾 备份与恢复

在悬浮球 → 账号与数据中选择“导出全部配置”，保存全部账号的名单、练度、备注、功能设置和用户黑名单；选择“导入全部配置”可恢复，确认后覆盖当前数据与设置。

配置备份不包含森空岛登录凭据、风险同意记录及自动刷新设置。恢复配置会清除当前保存的凭据，需要重新导入才能继续快捷刷新。油猴自身的备份与同步可能包含凭据，请妥善保管并清理旧备份中的明文。
