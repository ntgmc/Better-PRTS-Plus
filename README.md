## 📦 快速安装

1. 安装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/)（油猴）。
2. 打开 [GreasyFork 发布页（推荐）](https://greasyfork.org/zh-CN/scripts/558329-better-prts-plus)、[最新 Release 镜像安装](https://gh-proxy.com/https://github.com/ntgmc/Better-PRTS-Plus/releases/latest/download/Better-PRTS-Plus.user.js)或 [备用镜像](https://ghfast.top/https://github.com/ntgmc/Better-PRTS-Plus/releases/latest/download/Better-PRTS-Plus.user.js)。
3. 在油猴页面确认安装，然后打开 [prts.plus](https://prts.plus) 即可使用。

## ✨ 功能一览

| 功能 | 可以做什么 |
| --- | --- |
| 作业卡片增强 | 显示干员头像、关卡代号和具体上传时间，折叠长描述，将 Bilibili 链接整理为“参考视频”按钮。 |
| 持有干员与练度筛选 | 查找阵容齐全或可借助战补齐的作业，核对干员练度，并将不符合条件的作业置灰或隐藏。 |
| 多账号管理 | 按需添加账号，分别保存干员数据并随时切换；支持森空岛、文件和文本导入，以及全部配置备份。 |
| 界面调整 | 可选全站样式优化，统一导航、搜索筛选区、卡片和弹窗；适配原站深色模式，按需折叠侧边栏、隐藏视频作业和部分标签。 |

干员和模组数据会自动更新，无需重新安装脚本。

### 脚本更新

脚本会在打开页面时检查新版本，页面保持打开时每小时检查一次。发现新版本后，弹窗显示版本号、更新级别和更新内容，提供三个按钮：

- **仅重要更新提示**：以后只提醒重要和紧急更新；可在悬浮球 → 关于中关闭该选项，恢复全部提醒。
- **当前版本不再提示**：跳过弹窗中的新版本；有后续版本时，仍按你的设置提醒。
- **立即更新**：打开该版本的油猴安装页，确认安装后刷新页面。

普通更新主要调整功能和体验；重要更新包含影响核心功能的变更或修复；紧急更新用于需要尽快安装的修复。跳过多个版本后更新时，弹窗会一并显示这些版本的说明，并采用其中最高的更新级别。

打开悬浮球面板，点击“关于”，再点击“检查脚本更新”可手动检查，也可重新查看已跳过的版本。油猴自身的自动更新仍由扩展设置控制；上述偏好控制脚本内的弹窗提醒。

## 📖 使用指南

### 从森空岛导入

1. 在作业列表搜索框下方的筛选栏，或悬浮球 → 账号与数据中，点击“森空岛导入”。
2. 在打开的森空岛网页中登录，然后在右侧的 Better-PRTS-Plus 导入面板中选择要导入到的账号。
3. 点击“读取并导入干员”。如有多个明日方舟角色，选择要导入的角色。
4. 核对预览中的目标账号、人数变化和练度信息，确认导入后返回 PRTS Plus 使用筛选。

导入会替换目标账号的干员名单和练度数据，不会保存森空岛登录凭据。

### 从文件或文本导入

1. 打开悬浮球 → 账号与数据，选择要导入到的账号，再点击“导入干员数据”。
2. 点击“选择文件”上传 `.json` / `.txt` 文件，或粘贴文本后点击“导入粘贴内容”。
3. 核对预览中的目标账号、数据来源、新增与移除人数、是否包含练度，再确认导入。

| 数据来源 | 可用于 |
| --- | --- |
| MAA 导出的 JSON | 判断是否持有干员，并保留文件中的练度数据。 |
| TXT 文本（每行一个干员名称） | 判断是否持有干员；校验练度时会提示数据未知。 |

导入会替换目标账号原有的干员名单和练度。如果会移除已持有干员、降低练度或清空部分或全部练度，确认窗口会列出受影响的干员，需点击“确认覆盖并导入”才会写入；取消会保留原数据。只有名称的 TXT 不包含练度，覆盖已有练度前也会提示。

### 开启筛选

导入数据后，在作业列表搜索框下方的筛选栏选择：

| 按钮 | 作用 |
| --- | --- |
| 完美阵容 | 筛选出已拥有全部所需干员的作业。 |
| 允许助战 | 允许最多缺少 1 名干员，通过好友助战补齐。 |
| 校验练度 | 核对精英化、等级、技能等级与专精、模组和潜能。可单独开启，也可配合上述任一种筛选使用。 |
| 置灰模式 / 隐藏模式 | 选择将不符合条件的作业置灰或隐藏。 |

卡片会显示“缺 X 人”或“需助战：[干员名]”。开启“校验练度”后，练度不足的干员也会计入缺少人数；缺少练度数据时会显示提示。

筛选栏下方会统计本页作业数量，以及可用、需助战、待核验和不符合条件的数量；隐藏的视频作业会单独列出数量。未开启筛选时，只显示作业数量和筛选状态。作业集列表不显示作业统计或空列表提示；打开某个作业集后，抽屉内的作业列表上方会显示统计，只计算该作业集中的作业。

没有符合条件的作业时，会提示你调整条件、切换账号或查看其他页。隐藏模式下可点击“切换为置灰模式”，查看作业不符合条件的原因。待核验作业仍会显示，方便进一步核对。

在悬浮球 → 作业卡片 → 练度提示样式中，可选择默认的“缩略”或“完整”样式。缩略样式点击后展开详情；完整样式直接逐项对比“当前 / 作业要求”。

“点击关卡筛选”默认关闭，可在悬浮球 → 作业卡片中开启。开启后，点击卡片标题前的关卡代号徽章，或原站的关卡标签（如“灰石剧场 | 米诺斯 | 剿灭作战”），即可将该关卡应用到原站的关卡筛选器，保留其他筛选条件。也可用 Tab 聚焦后按 Enter 或空格触发；关闭后立即恢复普通展示。

### 切换与命名账号

- 在悬浮球 → 账号与数据中点击“添加账号”，填写昵称后即可导入数据；原有账号继续保留，账号数量可按需增加。
- 有 2 个账号时，点击筛选栏中的账号按钮即可轮换；有 3 个及以上账号时，通过下拉框选择。也可在悬浮球 → 账号与数据中直接切换，无需重新导入。只有一个账号时，切换按钮不可用。
- 点击账号旁的“删除”，确认后移除该账号的名单、练度和同步记录；至少保留一个账号，删除当前账号后自动切到剩余账号。
- 在悬浮球 → 账号与数据中点击“改名”，可设置“大号”“小号”等备注。未手动改名的账号会在森空岛导入成功后自动使用森空岛昵称。

### 调整显示偏好

点击页面侧边的悬浮球，选择分类后会向外展开对应的子面板：

| 分组 | 可调整的内容 |
| --- | --- |
| 作业卡片 | 折叠作业描述、干员头像、显示关卡代号、点击关卡筛选、显示完整上传时间、视频链接按钮、隐藏视频作业、隐藏 PRTS 类型标签、练度提示样式。 |
| 页面增强 | 全站样式优化、干员组弹窗头像、折叠侧边栏、隐藏原站干员匹配设置、公告分类标签。 |
| 账号与数据 | 添加、删除、切换和重命名账号，导入干员、森空岛导入、导出与导入全部配置。 |
| 关于 | 当前版本、项目资料、更新提醒偏好、手动检查更新。 |

“全站样式优化”默认关闭，可在悬浮球 → 页面增强中开启。开启后，导航、搜索筛选区、作业卡片、输入框和弹窗会使用统一的样式与间距。桌面侧栏会收窄，窄屏优先显示作业列表，并跟随原站的浅色、深色和高对比度主题。开启或关闭都会立即生效，无需刷新；该设置也会保存到全部配置备份中。

原站的“干员匹配设置”入口默认隐藏，关闭“隐藏原站干员匹配设置”即可恢复显示。

设置会自动保存。部分功能关闭后需要刷新，面板会提示“已保存，刷新后生效”；你可以先调整完所有设置，再点击“立即刷新”。导入配置也不会自动刷新页面。

面板会随悬浮球位置和可见屏幕空间自动调整，靠近底部时向上贴合；内容较多时在面板内滚动，刷新按钮保持可见。

分类子面板沿用设置面板的滑动、缩放和淡入淡出动画，根据悬浮球的位置向左或向右展开。窄屏下，面板会错开叠放，露出上一级的边缘。每次只展开一个分类；切换时收起上一个，并保留各分类的滚动位置。

再次点击当前分类、点击收起按钮或按 Escape，只会收起当前子面板。点击所有面板之外的区域、关闭设置或拖动悬浮球，会收起全部面板。系统开启减少动态效果时，面板会直接切换显示。

## 💾 备份与恢复

- 备份：在悬浮球 → 账号与数据中点击“导出全部配置”，保存全部账号的干员名单、练度、账号备注和功能设置。
- 恢复：点击“导入全部配置”，选择此前导出的备份文件，确认后覆盖当前账号数据和设置。更换浏览器或重装油猴后也可通过此方式恢复。

备份不包含森空岛登录凭据。

## 发布版本

发布前运行 `node tool/prepare-release.js --init X.Y.Z [normal|important|urgent]`，自动创建更新说明文件并登记版本；省略级别时默认为普通更新。编辑 `release-notes/X.Y.Z.md` 后运行发布脚本即可。直接发布尚未登记的版本时，也会自动生成文件并提示填写，重复运行会保留已有正文。

可运行 **Summarize Changes for Maintainer** 获取 AI 参考摘要，默认对比最新正式 Release 与 main，也支持指定基准版本 tag 或分析单个 PR；最终说明由维护者提供。

AI 接口配置、说明格式和发布命令见 [发布流程](RELEASE.md)。
