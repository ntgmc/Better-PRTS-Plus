## ✨ 核心功能

### 1. 🖼️ 作业卡片增强 (Visual Enhancement)
*   干员头像展示：将作业中的干员名称替换为头像网格，方便查看阵容需求。
*   资源自动更新：干员和模组数据会自动更新，自动选择可用的下载源或镜像，无需重新安装脚本。网络不可用时继续使用已缓存或内置的数据。
*   关卡信息提取：识别标题中的关卡编号（如 `7-18`, `H13-4`），并显示关卡徽章。
*   描述与链接整理：折叠较长的描述，将 Bilibili 链接显示为“参考视频”按钮。两项功能可分别开关。

*   具体时间显示：开启后，卡片直接显示上传时间，无需悬停查看。
*   独立功能开关：描述折叠、干员头像、关卡徽章、具体时间、视频链接优化、视频作业隐藏、PRTS 类型标签隐藏、干员组弹窗头像、侧边栏折叠、原站干员匹配设置隐藏和公告分类标签均可单独设置。关闭部分功能时，脚本会刷新页面，恢复原站内容。
*   配置管理：`CONFIG_DEFINITIONS` 定义各项功能的默认值、设置分组、开关标签和旧配置迁移规则。设置保存在 `prts_plus_settings` 中，导出全部配置时会包含各项功能设置。

### 2. 🔍 持有干员筛选 (Perfect Filter)
*   完美阵容：筛选出你已拥有全部所需干员的作业。
*   允许助战：筛选出最多缺少 1 名干员的作业，可通过好友助战补齐。
*   校验练度：可单独开启，也可与“完美阵容”“允许助战”一起使用。核对作业要求的精英化、等级、技能等级（8/9/10 对应专一/专二/专三）、模组和潜能。
*   练度提示：在悬浮窗的“练度提示样式”中选择“缩略”或“完整”。默认的缩略样式显示一行状态，点击可展开详情；完整样式逐项对比每名干员的“当前 / 作业要求”。数据未知时会显示提示，练度不足的干员也会计入助战缺口。
*   缺失提示：卡片显示“缺 X 人”或“需助战：[干员名]”，方便查看缺少的干员。
*   结果处理：不符合筛选条件的作业可以置灰保留，也可以隐藏。

### 3. 👥 多账号数据管理 (Multi-Account)
*   三组账号档位：可分别保存 3 个账号的干员数据。
*   账号切换：在筛选栏或悬浮球面板选择账号即可切换，无需重新导入文件。
*   森空岛导入：登录森空岛网页后，可通过脚本面板读取当前账号的明日方舟干员数据。
*   配置保存：开关状态和账号数据保存在油猴存储中，刷新页面后仍会保留。

### 4. 🌙 界面净化与深色适配
*   深色模式增强：调整 PRTS Plus 深色模式下的显示效果。
*   侧边栏净化：折叠较少使用的区域，给作业列表留出更多空间。
*   隐藏原站匹配设置：默认隐藏原站的“干员匹配设置”入口。在悬浮球面板的“页面增强”中关闭此项即可恢复显示。
*   悬浮设置面板：点击页面侧边的悬浮球即可开关功能，无需进入其他设置页。

## 📦 快速安装

1.  安装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/)（油猴）。
2.  选择安装来源：
    *   [GreasyFork 发布页（推荐）](https://greasyfork.org/zh-CN/scripts/558329-better-prts-plus)
    *   [GitHub 源码安装](https://github.com/ntgmc/Better-PRTS-Plus/raw/main/Better-PRTS-Plus.user.js)
3.  在油猴页面点击“安装脚本”。

## 📖 使用教程

### 第一步：导入您的干员数据
1.  点击页面右侧的设置悬浮按钮。
2.  点击“导入干员数据”。
3.  选择 `.json` / `.txt` 文件，或粘贴 JSON/TXT 文本后点击“导入粘贴内容”。
    > MAA 导出的 JSON 会保留练度数据；TXT 每行填写一个干员名字，只能用于判断是否持有。通过森空岛导入可同步技能和模组练度。

也可以从森空岛导入：
1.  在 PRTS Plus 的筛选栏或悬浮球面板点击“森空岛导入”，打开森空岛网页。
2.  登录森空岛，在页面右侧的 Better-PRTS-Plus 导入面板中选择账号档位。
3.  点击“读取并导入干员”。脚本会保存干员名称和练度数据，不会保存森空岛凭据或 token。

### 第二步：开启智能筛选
1.  找到作业列表搜索框下方的筛选控制栏。
2.  点击“完美阵容”或“允许助战”开启筛选。
3.  点击“置灰模式/隐藏模式”，选择不符合条件的作业如何显示。

### 第三步：自定义偏好
*   在悬浮球的设置面板中，可随时开关“卡片美化”“侧边栏净化”“链接优化”等功能。设置会自动保存到油猴存储中。
*   在悬浮球面板的账号区域点击“改名”，可为 3 个账号档位设置备注，例如“大号”“小号”“仅低配号”。尚未手动改名的账号会在森空岛导入成功后，自动使用森空岛昵称。
*   点击“导出全部配置”，可备份 3 个账号的干员数据、账号备注和界面偏好。更换浏览器或重装油猴后，点击“导入全部配置”并确认覆盖即可恢复。备份不包含森空岛凭据、token 或登录态。
