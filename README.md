## 📦 快速安装

1. 安装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/)（油猴）。
2. 打开 [GreasyFork 发布页（推荐）](https://greasyfork.org/zh-CN/scripts/558329-better-prts-plus)或 [GitHub 脚本文件](https://github.com/ntgmc/Better-PRTS-Plus/raw/main/Better-PRTS-Plus.user.js)。
3. 在油猴页面确认安装，然后打开 [prts.plus](https://prts.plus) 即可使用。

## ✨ 功能一览

| 功能 | 可以做什么 |
| --- | --- |
| 作业卡片增强 | 显示干员头像、关卡代号和具体上传时间，折叠长描述，将 Bilibili 链接整理为“参考视频”按钮。 |
| 持有干员与练度筛选 | 查找阵容齐全或可借助战补齐的作业，核对干员练度，并将不符合条件的作业置灰或隐藏。 |
| 多账号管理 | 保存 3 个账号的干员数据，随时切换；支持森空岛、文件和文本导入，以及全部配置备份。 |
| 界面调整 | 适配原站深色模式，按需折叠侧边栏、隐藏视频作业和部分标签，通过悬浮球集中调整设置。 |

干员和模组数据会自动更新，无需重新安装脚本。

## 📖 使用指南

### 从森空岛导入

1. 在作业列表搜索框下方的筛选栏或页面侧边的悬浮球面板中，点击“森空岛导入”。
2. 登录打开的森空岛网页，在右侧的 Better-PRTS-Plus 导入面板中选择目标账号档位。
3. 点击“读取并导入干员”。如有多个明日方舟角色，选择要导入的角色。
4. 核对预览中的目标账号、人数变化和练度信息，确认导入后返回 PRTS Plus 使用筛选。

导入会更新目标账号的干员名单和练度数据，不会保存森空岛登录凭据。

### 从文件或文本导入

1. 点击悬浮球，在账号区域选择目标账号档位，再点击“导入干员数据”。
2. 点击“选择文件”上传 `.json` / `.txt` 文件，或粘贴文本后点击“导入粘贴内容”。
3. 核对预览中的目标账号、数据来源、新增与移除人数、是否包含练度，再确认导入。

| 数据来源 | 可用于 |
| --- | --- |
| MAA 导出的 JSON | 判断是否持有干员，并保留文件中的练度数据。 |
| TXT 文本（每行一个干员名称） | 判断是否持有干员；校验练度时会提示数据未知。 |

导入会替换目标账号原有的干员名单和练度。如果会移除已持有干员、降低练度或清空部分或全部练度，确认窗口会列出受影响的干员，需点击“确认覆盖并导入”才会写入；取消会保留原数据。只有名称的 TXT 不包含练度，覆盖已有练度前也会提示。

### 开启筛选

导入数据后，在作业列表搜索框下方的筛选栏选择：

| 按钮 | 作用 |
| --- | --- |
| 完美阵容 | 筛选出已拥有全部所需干员的作业。 |
| 允许助战 | 允许最多缺少 1 名干员，通过好友助战补齐。 |
| 校验练度 | 核对精英化、等级、技能等级与专精、模组和潜能。可单独开启，也可配合上述任一种筛选使用。 |
| 置灰模式 / 隐藏模式 | 切换不符合条件的作业的显示方式。 |

卡片会显示“缺 X 人”或“需助战：[干员名]”。开启“校验练度”后，练度不足的干员也会计入助战缺口；缺少练度数据时会显示提示。

筛选栏下方会显示本页作业数量，以及可用、需助战、待核验和不符合条件的数量；隐藏的视频作业会单独列出。作业集列表不显示作业统计和空作业提示；打开作业集后，统计显示在抽屉内的作业列表上方，仅计算该作业集的作业。未开启筛选时只显示作业数量和筛选状态。没有符合条件的作业时会提示调整条件、切换账号或查看其他页；隐藏模式下可点击“切换置灰，查看作业”查看原因。待核验作业会保留显示，供进一步核对。

在悬浮球面板的“练度提示样式”中，可选择默认的“缩略”或“完整”样式。缩略样式点击后展开详情；完整样式直接逐项对比“当前 / 作业要求”。

### 切换与命名账号

- 在筛选栏点击账号按钮依次切换，或在悬浮球面板中直接选择账号，无需重新导入。
- 在悬浮球面板的账号区域点击“改名”，可设置“大号”“小号”等备注。未手动改名的账号会在森空岛导入成功后自动使用森空岛昵称。

### 调整显示偏好

点击页面侧边的悬浮球，按分组调整功能：

| 分组 | 可调整的内容 |
| --- | --- |
| 作业卡片 | 折叠描述文本、干员头像、关卡代号徽章、显示作业具体时间、视频链接优化、隐藏视频作业、隐藏 PRTS 类型标签、练度提示样式。 |
| 页面增强 | 干员组弹窗头像、折叠侧边栏、隐藏原站干员匹配设置、公告分类标签。 |

原站的“干员匹配设置”入口默认隐藏，关闭“隐藏原站干员匹配设置”即可恢复显示。

设置会自动保存；关闭需要刷新的功能后，面板会统一提示“已保存，刷新后生效”。可连续调整多个设置，完成后点击“立即刷新”。导入配置同样不会自动刷新。

面板会随悬浮球位置和可见屏幕空间自动调整，靠近底部时向上贴合；内容较多时在面板内滚动，刷新按钮保持可见。

## 💾 备份与恢复

- 备份：在悬浮球面板点击“导出全部配置”，保存 3 个账号的干员名单、练度、账号备注和功能设置。
- 恢复：点击“导入全部配置”，选择此前导出的备份文件，确认后覆盖当前账号数据和设置。更换浏览器或重装油猴后也可通过此方式恢复。

备份不包含森空岛登录凭据。
